# models/

학습된 모델 파일과 전처리 객체를 저장하는 폴더다.
**모델 파일 본체는 Git에 올리지 않는다** (`.gitignore` 처리됨).

## 규칙

1. 모델을 저장할 때 전처리 객체(스케일러, 인코더 등)를 **함께** 저장한다.
2. 파일명에 모델 종류와 버전을 넣는다. 예: `rf_baseline_v1.pkl`
3. 모델을 만들면 아래 표에 성능과 조건을 기록한다.
4. 실제 파일은 팀 공유 드라이브로 주고받는다.
